# Standardized Product Brief: Conxian Gateway
- **Role**: High-Performance Institutional Bridge (The Routing Layer)
- **Architecture**: Rust (Actix-web), Actix-actor system.
- **UVP**: Orchestrates cross-chain atomic swaps (Stacks, Liquid, Rootstock) and provides tiered institutional access with MVCR-compliant reporting.
- **Dependencies**: bitcoincore-rpc, Stacks Node API, secp256k1.
- **Positioning**: The "B2B Onramp" for corporate treasury and institutional liquidity.
