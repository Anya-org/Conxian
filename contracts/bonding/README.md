# Bonding Module

## Overview

The Bonding Module contains contracts related to bonding curves and bond tokens within the Conxian Protocol.

## Status

**Partial Implementation**: Some contracts are implemented while others remain as empty stubs.

## Current Files

- `bond-factory.clar` - **IMPLEMENTED**: Bond factory contract (8,369 bytes)
- `cxd-bonding-curve-amm.clar` - **IMPLEMENTED**: CXD bonding curve AMM (1,290 bytes)
- `bond-issuance-system.clar` - **EMPTY**: Stub implementation
- `bond-token.clar` - **EMPTY**: Stub implementation

## Implementation Details

The `bond-factory.clar` and `cxd-bonding-curve-amm.clar` contracts provide functional bonding curve capabilities for CXD token initialization and automated market making.
