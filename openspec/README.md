# OpenSpec

OpenSpec is the public specification set for Conxian. The goal is to make the system easier to evaluate and integrate by documenting key requirements and invariants up front.

## Purpose

- Provide a public, versioned specification set for Conxian.
- Capture requirements and invariants needed for independent evaluation and integration.

## Status

active — OpenSpec is maintained as the public source of truth for Conxian technical specifications.
