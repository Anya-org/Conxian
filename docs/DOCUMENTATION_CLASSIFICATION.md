# Documentation Classification (ZSE)

To maintain Zero Secret Egress (ZSE) compliance, all Conxian documentation is classified into two categories: **Public-Safe** (Git) and **Internal-Only** (Linear Virtual Office).

## Public-Safe (Keep in Git)
- **Technical Specifications**: OpenSpec, CJCS, and architecture diagrams that do not reveal exploit-enabling implementation details.
- **Governance Standards**: Repo policies, contribution guidelines, and public-facing operating models.
- **Product Documentation**: User guides, PRDs (scrubbed of internal strategy), and integration manuals.
- **Trust Messaging**: Security principles, audit summaries, and brand narratives.

## Internal-Only (Store in Linear Virtual Office)
- **Strategy**: Valuation models, M&A velocity, competitive intelligence, and confidential partnership notes.
- **Legal**: Unredacted contracts, jurisdictional filing details, and sensitive legal counsel.
- **Operations**: Incident response runbooks with privileged access steps, internal infrastructure maps, and signing key custody procedures.
- **Administrative**: Secret provisioning, vendor account credentials, and unredacted financial projections.

## Reference Rule
If an internal-only document must be referenced from Git, provide a ZSE-compliant summary and a direct link to the canonical Linear document.
