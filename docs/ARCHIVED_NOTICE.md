# Repository Archival Notice

> **NOTICE**: This repository (`Conxian/Conxian`) has been officially **ARCHIVED** and placed into **READ-ONLY** status. No further updates, feature developments, security patches, or pull requests will be accepted.

---

## Overview

As part of the protocol lifecycle transition, the core repository has been archived. All smart contracts, documentation, deployment plans, and historical records remain fully accessible for public review, auditing, and reference.

## Repository Governance & Ruleset Status

1. **Read-Only Mode**:
   - The repository is read-only. Commits, pull requests, issues, and releases are frozen.
2. **Protection Checks & Rulesets Disabled**:
   - All required PR status checks (`protocol-merge-gate`, `jules-audit`, `gitleaks`, `dependency-review`) have been disabled.
   - Ruleset review requirements and mandatory Code Owner review gates have been deactivated.
3. **Automations & CI/CD**:
   - OpenHands, GitHub Actions, and deployment preflight automations are set to passive/disabled mode.

## Public Access & Forking

- **Source Code**: All Clarity 4 smart contracts under `contracts/` remain available under the GPL-3.0 License.
- **Documentation**: All specifications, research papers, ADRs, and runbooks under `docs/` remain preserved as static reference materials.
- **Forking**: Developers and community members wishing to build upon Conxian protocol primitives are encouraged to fork the repository.
